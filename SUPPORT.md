# Support

Use public issues for reproducible product bugs and feature requests. Use Discussions for questions, examples and community conversation.

Include the affected surface, browser or app version, steps to reproduce, expected behavior and actual behavior. Redact screenshots and logs before sharing.

Billing, login, workspace access and other account-specific requests belong in the support channel on https://busymate.ai. Never post passwords, API keys, access tokens or customer data here.

Maintainers may track implementation privately and post public progress and resolution back to your report. A closed report should explain the fix, workaround, duplicate or reason for closure.
