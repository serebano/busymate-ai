# Contributing

Thank you for helping improve Busymate AI. You can contribute bug reports, feature requests, documentation corrections and examples.

Search existing issues and discussions before opening a new report. Keep each issue focused on one problem. For documentation changes, open a small pull request describing the change and verify its links.

This repository does not contain the product source. Product implementation and releases are maintained separately. Public feature requests are input to prioritization, not delivery commitments.

## Maintainer triage

New bug reports and feature requests receive a type label and `needs-triage`.
Maintainers review the affected surface, reproduction details, and whether the
report can be reproduced with a non-customer test account. Add context or a
status label, link duplicates, and close reports that are out of scope with a
brief explanation. Public reports do not commit to a release date.

Keep billing, login, workspace access, customer conversations, personal data,
credentials, tokens, and private logs out of issues and discussions. Use
[account support](https://busymate.ai/contact) for account-specific help and
[private vulnerability reporting](https://github.com/serebano/busymate-ai/security/advisories/new)
for security reports. If sensitive information is posted publicly, remove or
redact it promptly and direct the reporter to the appropriate private channel.

Be respectful, stay on topic and protect other people's privacy. Harassment, spam and disclosure of private information are not welcome.
