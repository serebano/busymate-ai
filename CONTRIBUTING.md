# Contributing

Thank you for helping improve Busymate AI. You can contribute bug reports, feature requests, documentation corrections and examples.

Search existing issues and discussions before opening a new report. Keep each issue focused on one problem. For documentation changes, open a small pull request describing the change and verify its links.

This repository does not contain the product source. Product implementation and releases are maintained separately. Public feature requests are input to prioritization, not delivery commitments.

Be respectful, stay on topic and protect other people's privacy. Harassment, spam and disclosure of private information are not welcome.
