# Security reporting

Do not report vulnerabilities, credentials or private customer data in a public issue or discussion.

Use GitHub's private vulnerability reporting for this repository when available: https://github.com/serebano/busymate-ai/security/advisories/new. Otherwise use the private support channel on https://busymate.ai and identify the message as a security report.

Provide affected URLs, reproducible steps, impact and a minimal demonstration. Do not access other users' data or disrupt the service while reproducing a report.
